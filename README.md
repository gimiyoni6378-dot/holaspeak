# HolaSpeak

모바일 중심의 스페인어 초급 학습 사이트입니다.

## 기능

- 초급 학습 여정과 짧은 일일 미션
- 객관식 레슨, 단어 복습, 짝 맞추기, 문장 조립 게임
- 주간 학습 기록과 샘플 리그
- 학습 기록은 브라우저의 로컬 저장소에 저장됩니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 외부 빌드 도구는 필요하지 않습니다.

## 파일

- `index.html`: 한국어 화면과 학습 코스
- `style.css`: 반응형 모바일 UI
- `app.js`: 레슨, 게임, 로컬 진행 기록
